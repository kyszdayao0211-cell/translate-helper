## 翻译助手插件：「检查全表」结果按颜色过滤

用户需求：检查全表的结果面板加"红色/黄色/蓝色"过滤。

- 颜色 ↔ tier 映射（`TranslationWorkspace.jsx` 新增常量 `TIER_COLOR`）：
  - 红 = `MISSING`（漏译/截断）+ `CONFIRMED`（术语不一致）
  - 黄 = `REVIEW`（疑似不一致待复核）
  - 蓝 = `GLOSSARY_DRIFT`（术语库疑似过时）
- 实现：
  - 新增 state `tierFilter`（`all | red | yellow | blue`）；`openSidePanel` 时重置为 `all`，避免上次筛选把新结果筛空。
  - return 前计算 `filterCounts`（各色条数）与 `visiblePanelItems`（过滤后的列表）。
  - 侧边栏 summary 下方加一排 filter chip（全部/红色/黄色/蓝色 + 条数），0 条时置灰；选中时用对应色浅底。
  - 列表渲染、`>200 条`提示、空状态均改用 `visiblePanelItems`。
  - `handleExportInconsistencies` 改为导出**当前筛选**下的条目。
- 样式：`styles.css` 新增 `.side-panel-filter-row / -chip / -dot / -count`、`.dot-red|yellow|blue`、`.chip-*-active`、`.side-panel-empty`（light 主题）。
- `USER_GUIDE.md`：4.2 表格更新「检查全表」说明；新增 4.7「检查结果按颜色筛选」、4.8「导出检查全表结果」（跟随筛选），原 4.8/4.9 顺延为 4.9/4.10。
