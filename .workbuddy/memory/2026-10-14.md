## 翻译助手插件：术语表 JSON 上传报"格式错误"排查

- 用户反馈上传术语表（JSON）到插件报"格式错误"。
- 定位：上传入口为 `src/panel/TermLibrarySelector.jsx` 的 `handleImportGlossaryFile`（按钮："文档术语库 (_glossary / _guide) → 从 JSON 导入（覆盖）"），dist 构建产物 `dist/assets/panel-CcjG8kOe.js` 逻辑一致。
- 根因：解析代码要求 **顶层必须是数组、每项含 `source`/`target`/`notes` 字段**；用户 JSON 顶层多为对象包装（如 `{"terms":[...]}`）→ 触发 `throw new Error('格式错误')`。次因：字段名写成 `note`（正确是 `notes`）或中文/自定义字段名 → 不报错但导入空内容。
- 产出：`convert-glossary.cjs`（项目根目录）——容错转换脚本，支持顶层数组、对象包装（terms/data/glossary 等键）、中文字段名（原文/译文/备注）、二维数组带表头、JSON Lines、`note`→`notes`，带字段映射报告和前 3 条预览。用 `.cjs` 后缀是因为项目 package.json 有 `"type": "module"`。
- 注意：该导入是 **覆盖写入** 整个 `_glossary` 标签页，操作前建议先"导出 JSON"备份。

## 翻译助手插件：术语表支持 Excel/CSV 直接导入导出

用户嫌每次要先转 JSON，要求改成直接上传/导出表格文档。

- 新增 `src/utils/glossaryFile.js`（零依赖，沿用 docx.js 的 ZIP 手写解析风格）：
  - xlsx 解析：ZIP 中央目录遍历 → `xl/sharedStrings.xml` + `xl/worksheets/sheet1.xml`，支持 `t="s"`/`inlineStr`/`str`/`b`/数字，按 `r="A1"` 属性定位单元格（正确处理空单元格）；表头自动匹配（source/target/notes、原文/译文/备注等别名），无表头按 A/B/C 顺序
